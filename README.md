# Dues

**Get paid on the first, from any chain, without ever buying NEAR.**

Dues is recurring invoicing for freelancers. A client pays from whatever chain and token they already hold; the freelancer receives USDC on NEAR with gas sponsored by a relayer. Invoices show paid, pending and refunded status with transaction links, and export to a CSV an accountant can read.

## Status

In active development. Setup instructions, architecture and a demo will land here as the build progresses.
